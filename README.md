# Wearable Insulin Cooling Device

This project explores the development of a wearable cooling sleeve designed to protect insulin pumps and insulin patches from thermal degradation in extreme heat environments.

The device was designed for lower-income individuals with Type 1 diabetes living in rural communities experiencing energy insecurity and prolonged heat exposure.

## Project Overview
The system integrates:
- Arduino-based temperature monitoring
- Automated fan activation
- LED alert indicators
- Wearable compression sleeve integration
- Active cooling logic for insulin protection

The prototype was designed to maintain insulin below the critical degradation threshold of 30°C while remaining lightweight, affordable, portable, and easy to use.
